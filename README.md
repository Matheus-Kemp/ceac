# CEAC

Site do TFG "Entre o Legado e a Continuidade": requalificação do CEAC de Iracemápolis-SP. Matheus Kemp, Arquitetura e Urbanismo, 2026.

No ar em https://matheus-kemp.github.io/ceac/

Fotos: `fotos/matheus-kemp.jpg` e `fotos/daniel-andrioli.jpg` (retrato 4:5).

Galeria (seção 06): cada imagem é um `.quadro` no `index.html`, com `<img src="galeria/nome-mini.jpg" data-grande="galeria/nome.jpg" alt="...">` e o título em `<span class="titulo-quadro"><strong>...</strong></span>` (só para leitor de tela e para a legenda da tela cheia). `-mini` tem até 1100 px; a versão grande, até 2600 px. Itens com a classe `desenho` (pranchas) aparecem inteiros, sem corte, sobre fundo branco. As imagens de 17/11/2026 vêm dos renders do Lumion de 29/10 e de recortes do PDF das pranchas de 17/11.
